# The Orange Calendar 🟠📅

The Orange Calendar allows you to import all your currently scheduled Home Depot shifts into your calendar app in under a MINUTE! This started as a personal project because my everyday task management revolved around Apple Calendar to keep things organized. Workforce does not allow you to connect your scheduled shifts to Calendar, which was why I built this tool. 

## How it Works
This tool requires a Workforce PDF export of your schedule in order to read and parse all important data from the PDF to automatically create calendar events for each shift. After importing the generated .ICS file into your calendar, your events will have a location of 
the store as well as reminders of when your shift is about to begin. The location of the store is found by using the store number located in the Workforce PDF, a dataset containing the majority of Home Depot addresses.
